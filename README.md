> **Concept:** Matrix-Inspired Aesthetic Terminal / Bio-Card

---

## 🚀 Overview

**ASJAD AHMAD // DIGITAL IDENTITY** is a futuristic, Matrix-inspired digital identity system and interactive developer terminal created for the **TechnoJam 2026 VibeCoding challenge**. 

Instead of a generic template, this project immerses the visitor in a cohesive cyber interface containing Asjad Ahmad's digital identity. Visitors experience an authentic green-code Matrix rain animation with variable drop speeds, a cinematic bootloader sequence, a comprehensive identity HUD, learning project logs, chaotic developer humor, and a fully interactive bash-style terminal supporting commands, command history, and hidden Easter eggs.

---

## 🎯 Challenge Requirements Satisfied

This project directly implements the **Easy-Level Challenge** of TechnoJam 2026:
> *"Matrix-Inspired Aesthetic Terminal / Bio-Card"*

### Core Deliverables:
1. **Matrix Digital Rain Canvas:** Multi-speed falling character columns, varying stream lengths, brighter white leading characters, and intensity modulation during transitions and hacking sequences.
2. **Cohesive Terminal & Bio-System:** Displays authentic profile data for Asjad Ahmad, 1st-year BCA student at Galgotias University.
3. **Interactive Terminal & Buttons:** Functional bash terminal (`ASJAD@DIGITAL-ID:~$`) with command history (`↑` / `↓` keys) supporting `whoami`, `about`, `skills`, `projects`, `status`, `joke`, `date`, `hack`, `clear`, and `sudo hire asjad`.
4. **Chaotic & Harmless Developer Humor:** A curated bank of 24 self-aware, sarcastic developer quotes with an interactive `[ NEW QUOTE ]` system widget.
5. **Two Reliable Easter Eggs:**
   - **Easter Egg 01:** Hidden keyword trigger (`matrix` / `secret` / 3 clicks on status node) unlocking `SECRET MODE ACTIVATED / +100 AURA` and a golden Matrix rain overload.
   - **Easter Egg 02:** Terminal command `sudo hire asjad` triggering a humorous permission check and qualification review.
6. **Dark Cyber Aesthetic:** Deep black background (`#040704`), controlled neon green highlights (`#00ff41`), glassmorphic dark panels, scanlines, and monospace typography.
7. **Intentional Responsiveness & Accessibility:** Tested from 390px mobile screens up to 1920px desktop displays with zero horizontal overflow, visible focus indicators, and `prefers-reduced-motion` compliance.
